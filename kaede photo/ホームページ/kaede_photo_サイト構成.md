## 7. よくある質問ページ（FAQ）

**Q1. 撮影場所はどこでもいいですか？**
```
はい、ご希望の場所で撮影いたします。公園・お家・神社・レンタルスタジオなど、
「家族らしい場所」をぜひご相談ください。
※ 場所によっては事前に許可が必要な場合がございます。
```

**Q2. 雨の日はどうなりますか？**
```
雨天・荒天の場合は無料で日程を変更いたします。
曇り程度であれば撮影可能な場合もありますので、当日の天候を見てご相談ください。
```

**Q3. データはどうやって受け取れますか？**
```
オンラインアルバム（データ納品サービス）のURLをメールにてお送りします。
スマートフォン・PCからダウンロードいただけます。
```

**Q4. 子どもが泣いてしまったり、動き回っても大丈夫ですか？**
```
大丈夫です！子どものペースに合わせてゆっくり撮影します。
泣き顔も、走り回る姿も、全部が思い出の1枚になります。
```

**Q5. 服装はどうすればいいですか？**
```
特に決まりはありませんが、家族で色をそろえたり、白・ベージュ・くすみカラーでまとめると
統一感が出やすいです。ご希望の方にはアドバイスもいたします。
```

**Q6. 撮影した写真は全部もらえますか？**
```
プランに記載のカット数の中から、カメラマンがセレクト・レタッチしてお渡しします。
「ご自身でデータ選択」オプションを追加いただくと、お客様がお好みのカットを選べます。
```

**Q7. 予約から撮影までの流れを教えてください。**
```
① フォームを送信
② メールにてご確認のご連絡（2営業日以内）
③ 安心保証金 2,000円（PayPay）をお支払い → 予約確定
④ 撮影当日
⑤ 撮影終了後、安心保証金 2,000円を全額返金
⑥ 約1ヶ月後にデータ納品
```

**Q8. ⚑ 個人情報はどのように管理されますか？**

お預かりした個人情報は、ご予約の確認・ご連絡・データ納品のみに使用します。
