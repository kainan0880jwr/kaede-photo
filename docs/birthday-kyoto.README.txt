■ birthday-kyoto.html について（未公開の下書き）

2026/9/12 の京都撮影会「BIRTHDAY in kyoto」用に作成したページです。
予約が満席になったため、公開せずに保留しています。
本番（kaede-photo.com）には出ていません。GitHubにも上げていません。

────────────────────────────────
次回の撮影会で再利用する手順
────────────────────────────────

【1】このHTMLの中で書き換える箇所

  ・開催日        「2026.09.12」「2026年9月12日（土）」「9月12日（土）」
                  JS内の EVENT_DATE = '2026-09-12'
                  構造化データ（JSON-LD）の startDate / endDate
  ・時間枠        Schedule セクションの slot-card 4つ
                  予約フォームの #c-slot1 / #c-slot2 の option
  ・料金          Plan セクションの plan-card 2つ
                  予約フォームの #c-plan の option（value がプラン名）
  ・会場          「STUDIO UNFIL」「京都府京都市右京区右京極橋詰町2-1 2F」
  ・定員          「先着4組」「残り◯枠」
  ・開催条件      「2組以上のお申し込みで開催」（4箇所）

【2】満席の管理（ページ下部のJS）

  const SOLD_OUT_SLOTS = ['①', '②'];

  この配列に枠番号を足すだけで、日程カード・予約フォームのプルダウン・
  残り枠カウンターの3つが自動で切り替わります。
  空配列 [] で全枠受付中、['①','②','③','④'] で全枠SOLD OUT＋フォーム停止。

【3】公開する前に必ず行う2つの設定（これを忘れると予約が壊れます）

  (a) netlify/functions/booking.js の ALLOWED_PLANS に、
      #c-plan の option value と「完全に同じ文字列」を追加する。
      例： 'BIRTHDAY in kyoto 30cuts ¥15,000',
           'BIRTHDAY in kyoto 40cuts ¥18,000',
      ※ここが1文字でも違うと「ご希望のプランが正しくありません」で
        予約が弾かれます。

  (b) netlify.toml に拡張子なしURLのリダイレクトを追加する。
      [[redirects]]
        from = "/birthday-kyoto"
        to = "/birthday-kyoto.html"
        status = 301
        force = true

  ※ (a)(b) は掲載取りやめに伴い、いったん元に戻してあります。

【4】画像

  images/kyoto-*.jpg / .webp （フライヤー由来・変換済み）
  ページ本体では baby-9 / baby-12 / baby-5 / family-9 を使用しています。
  kyoto-1-hero.jpg はSNSシェア用のOG画像として指定しています。
